# Portal Estudiantil SIGPS

Sitio público y estático de la Facultad Multidisciplinaria Oriental de la Universidad de El Salvador para consultar información del proceso de servicio social, el catálogo de formatos F1–F8 y un checklist informativo.

No requiere autenticación ni administra expedientes, archivos enviados o trámites individuales. Los nombres, versiones y archivos oficiales de los formatos, así como los requisitos y las horas por programa, deben confirmarse con la Unidad de Proyección Social antes de publicarse como definitivos.

Abre `index.html` para ver el portal.
